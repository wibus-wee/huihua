The complete topic projection is retained once as a metadata evidence record, ahead of selected journal records; no temporal ordering is claimed between that current projection and past events.
Historical console/log task records, archived journal containers and arbitrary config-driven layouts are not currently decoded.
Acquired native journal JSONL can be parsed directly, with topic attribution retained and no directory discovery; it is a capture view, not a per-topic query.
Synthetic fixtures validate current schema, cross-topic selection and repeated snapshots.
