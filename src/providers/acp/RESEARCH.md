# ACP recording compatibility evidence

| Official facts                                                                                                                                                                                                                                                                                                                                                                                                           | Third-party compatibility experience                                                   | Huihua decisions                                                                                                                                                                                                                                                                          |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [v1 schema](https://github.com/agentclientprotocol/agent-client-protocol/blob/e73e5603c54f9435123d609c3503ec16aa8ab0d8/schema/v1/schema.json) and [v2 schema](https://github.com/agentclientprotocol/agent-client-protocol/blob/e73e5603c54f9435123d609c3503ec16aa8ab0d8/schema/v2/schema.json) define session/update notifications and JSON-RPC methods. ACP does not define a universal export container or directory. | Export wrappers are client-specific; none was supplied for this task.                  | Accept one JSON-RPC object or bare SessionNotification per JSONL line. Do not claim support for arbitrary client archives, JSON arrays, Markdown or live protocol connections.                                                                                                            |
| Loading a session can replay chunks with repeated message IDs. v2 also reports complete message upserts and nullable patches.                                                                                                                                                                                                                                                                                            | A capture may include outbound prompt requests and the corresponding replay or echo.   | Keep every chunk, request and complete-message observation in order, without merging or deduplication. Null/omitted message content stays system evidence instead of inventing text.                                                                                                      |
| Tool updates are patches; v1 tool_call has a display title, while v2 may have a programmatic name. Only status completed/failed establishes a final outcome.                                                                                                                                                                                                                                                             | Joining partial updates requires state and can hide the original facts.                | A v1 call uses its explicit title, labeled tool_name_origin; a v2 call requires name and rawInput. Keep incomplete patches as system events, complete updates as separate results, with the whole update object. Never guess a missing name or input from earlier updates.                |
| v1 diff carries path/newText and optional oldText. v2 diff carries authoritative operations and paths, with optional patch text.                                                                                                                                                                                                                                                                                         | Locations identify affected paths but do not prove a file change.                      | Emit file_change only for explicit diffs. Missing oldText gives unknown operation; null gives create. Map v2 add/copy to create and move to rename; retain oldPath, original operation and patch format in metadata. Do not read referenced files.                                        |
| Multiple sessions may use one transport. Session IDs are explicit notification fields.                                                                                                                                                                                                                                                                                                                                   | Combining them into one conversation contaminates history and matches unrelated tools. | This provider reads one session capture: first native identity wins; foreign-session lines stay unknown records with diagnostics. Use separate captures for independently selectable sessions. Numeric request IDs remain in metadata even when a string canonical requestId is provided. |

The shared ACP mapper is owned by `src/shared/acp.ts`; native Grok storage reuses it without importing another provider.
Unknown methods, updates and future handshake versions remain evidence.
No JSON-RPC client, agent execution, response matching, protocol migration or relationship cache is installed.
Fixtures exercise both stable schemas and preservation of partial/unknown data, not live product behavior.
