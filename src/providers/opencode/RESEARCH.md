# OpenCode compatibility evidence

Directory recognition now requires native identity matching the metadata filename and session facts
(title, native creation time or the confirmed older directory/time shape).
Current legacy ses_*.json names
are accepted; older full directory/time metadata remains compatible with the historical fixture.
Message/part records and JSON without session facts cannot become refs merely because a path contains session/info.
Exact caller-supplied metadata files remain supported for portable and damaged-source acquisition.
