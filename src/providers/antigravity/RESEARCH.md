The [pinned Agent Sessions discovery](https://github.com/jazzyalex/agent-sessions/blob/6fa9a73f489d37f655873871e5e6a5cf6975d1ff/AgentSessions/Services/AntigravitySessionDiscovery.swift) and [captured transcript](https://github.com/jazzyalex/agent-sessions/blob/6fa9a73f489d37f655873871e5e6a5cf6975d1ff/Resources/Fixtures/stage0/agents/antigravity/cli_small.jsonl) establish additional third-party CLI/IDE brain evidence.
Default discovery includes ~/.gemini/antigravity-cli/brain and ~/.gemini/antigravity/brain alongside conversations.
CLI */.system_generated/logs/transcript.jsonl requires native step_index/type facts during directory discovery; exact JSONL files remain explicit acquisition.
The existing shared JSONL pipeline maps USER_INPUT, PLANNER_RESPONSE thinking/content/tools, explicit tool outcomes and known controls.
Native created_at and truncated_fields remain intact; truncation is diagnosed.
No tool IDs are invented from preceding calls.
Unknown steps, including private browser/protobuf variants, remain complete evidence.
Markdown files use the additive antigravity_markdown format and bounded UTF-8 acquisition, retained as raw artifact plus system evidence.
They establish no conversation, workspace, model, event timestamp or tool relationship; referenced links/current files are never opened.
These observed formats have no official schema guarantee and do not replace the SQLite decoder or certify all server/IDE versions.

Fixtures are handwritten SQL with synthetic Protobuf records, generated into SQLite only by `pnpm fixtures --regenerate`.
SQL fixtures validate the observed binary subset.
The separate pinned JSONL captures validate recorded CLI facts, not every server/IDE generation.
Use the OAR or ACP provider for protocol recordings of the packaged server.

The codec dependency decision, installation cost and alternatives are owned by [architecture](../../../docs/architecture.md#dependency-and-ingestion-decisions).
