# Huihua v0.4.4

This release adds an extension decoder API and improves Pi session discovery.

## Features

- Add `SessionDecoder`: synchronous per-replay decoders that contribute events, extension metadata and parent-session candidates from raw records, available via `createPiProvider({ decoders })` and third-party `jsonlProvider` adapters.

## Bug Fixes

- Reject non-session JSONL files during Pi discovery.
