# Huihua v0.4.1

This release improves session compatibility and fixes token usage reporting across supported coding agents.

## Features

- Support Antigravity CLI JSONL transcripts and Markdown artifacts.
- Support Grok chat histories and native subagent metadata.

## Bug Fixes

- Fix Kimi message and tool parsing, and count all four native token counters without double-counting mirrored usage.
- Restore Codex usage model attribution from recorded turn context while keeping missing models unknown.
- Improve tool results, errors and metadata handling for Cursor, Claude, DeepSeek, Droid, Hermes, Copilot and Qwen.
- Fix Devin SQLite reads with commented schemas and preserve recorded image attachments.
- Fix Grok Linux permission errors when importing portable files.
- Expand local session discovery and metadata support for Cline, Claude, OpenClaw and fx.
- Fix JSONL resource cleanup on completion, early return and cancellation.

## Performance

- Reduce repeated OpenCode database scans while preserving native order and session evidence.
