# Huihua v0.4.1

This release fixes native-session compatibility and Usage accounting across the
provider set, and adds missing historical acquisition surfaces.

## Fixed

- Kimi loop events now expose assistant text, reasoning, media and native tool
  calls/results.
  ID-less state metadata supplies recorded title, workspace and
  timestamps independently of session identity.
- The private Usage CLI sums Kimi's four native generation counters, including
  session-scoped compaction, without adding mirrored step-end counters twice.
  Codex usage can use compatible recorded turn-context models with explicit
  provenance; model changes, missing contexts, turn boundaries and malformed
  records cannot leak a model into unrelated usage.
- The SQLite schema reader recognizes comments without changing quoted
  identifiers/defaults, restoring reads of Devin's native commented DDL.
  Devin's explicitly recorded sibling images also become media events.
- OpenCode traverses message and part tables once per selected session while
  preserving native ordering, selected evidence and orphan diagnostics.
- Cursor CLI tool aliases, Hermes recorded tool failures, DeepSeek v2/v3 result
  identities/errors and parent metadata, Droid tool-result/workspace aliases,
  and Copilot tokenDetails-only shutdown observations are normalized correctly.
- Cline honors `CLINE_DATA_DIR` with explicit-root precedence and isolated
  `homeDir` discovery.
  Claude discovers `.ndjson` histories, maps historical
  top-level tools and reads matching Desktop title sidecars.
  OpenClaw discovers
  deleted JSONL history, and fx retains optional display titles and checkpoint
  preferences.
- Qwen preserves display-only tool results with provenance, prefers native
  functionResponse without duplicate results, and classifies runtime
  notifications as system evidence.
- JSONL sources finish asynchronous closure before consumption returns,
  including early return, callback failure and cancellation.
- Grok portable imports acquire adjacent metadata without searching unrelated
  sibling directories, fixing permission errors on Linux temporary paths.
  Native subagent lineage and explicit companion permission errors remain preserved.

## Added

- Antigravity CLI brain JSONL transcripts and bounded brain Markdown artifacts,
  alongside the existing observed SQLite/Protobuf steps reader.
  Markdown remains
  raw artifact/system evidence; it does not invent conversation or workspace facts.
- Grok derived `chat_history.jsonl` acquisition and native sibling subagent
  metadata.
  Directory discovery prefers `updates.jsonl`; an explicitly selected
  history file remains readable.
- Twelve pinned, unmodified Agent Sessions compatibility artifacts and 27
  focused compatibility regressions, plus a portable Grok acquisition regression
  and a provider-by-provider acceptance report.

## Compatibility and validation

The session schema remains `agent-session/v1`.
Complete native records, repeated
IDs, source order and unknown data remain preserved; static semantic baselines
are unchanged.
New source formats and inherited Codex model provenance are
additive.
The Usage CLI remains a private example workspace package and retains
`huihua-usage/v2`; cumulative Codex snapshots, turn summaries and Copilot process
summaries are preserved but excluded from additive response/day totals.

`pnpm check` passed all 410 tests, architecture/dependency policy and installed
ESM package verification.
The [CI matrix](https://github.com/wibus-wee/huihua/actions/runs/37704122234)
also passed on Ubuntu / Node 22.18 and macOS / Node 24.
Real Kimi counters independently matched the CLI
exactly, and OpenCode completed a full local report.
Devin discovery succeeds;
full live-store Usage validation remains limited by concurrent external writes
and continues to fail explicitly when the source changes during reading.
See the [compatibility acceptance report](https://github.com/wibus-wee/huihua/blob/v0.4.1/docs/compatibility-acceptance.md) for
behavior assertions, native-counter comparisons and remaining evidence limits.
