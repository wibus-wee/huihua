# Huihua v0.4.6

This release accepts reviewed producer format drift across Claude Code, Codex, Copilot and Hermes.

## Improvements

- Preserve Claude Code 2.1.300+ subagent `api-request`, `api-request-shape` and `api-request-blob` records as child rows when they are file-backed inside a matching `agent-<agentId>.jsonl` transcript, without inferring provider semantics from the request payload.
- Accept Codex 0.163.0 response metadata (`status`, empty `annotations`/`logprobs`) and the reviewed repeated `thread_settings_applied` shape alongside the existing 0.161.0 and 0.162.0 variants.
- Accept Copilot CLI 1.0.97 system-message drift and the 1.0.98 `sessionWasActive` resume field while keeping system payloads and event mapping unchanged.
- Accept Hermes pinned/latest `state` inventory row variants without assigning canonical meaning to the new runtime counters or routing metadata.
- Refresh compatibility baselines for Claude, Copilot, Codex, Hermes, Qwen, Grok and ACP.
