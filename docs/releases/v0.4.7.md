# Huihua v0.4.7

This release adds support for fx v2 journals and updates producer compatibility coverage.

## Improvements

- Discover and read fx v2 `log.jsonl` journals, preserving native records and mapping supported conversation and session events.
- Refresh producer compatibility evidence and baselines across supported providers, including Claude Code, Codex, Copilot CLI and fx.
- Bound Codex compatibility diagnostics and improve provider import checks.
