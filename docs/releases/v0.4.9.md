# Huihua v0.4.9

This patch release improves bounded JSONL discovery reads without changing public APIs or the `agent-session/v1` schema.

## Improvements

- Prefetch JSONL headers and companion metadata through an eight-item read window while preserving traversal and failure emission order.
- Size discovery stream chunks to the configured header limit instead of the full-session read size; full transcript reads retain their existing chunk size.

## Development and compatibility

- Add a local session explorer in the repository's web workspace; it is not included in the `huihua` npm package.
- Review November 19–20 native metadata drift for Claude Code, Copilot CLI, DeepSeek, Grok, Codex and OAR without changing production provider mappings.
- Fix the OpenCode live compatibility harness's synthetic model registration so it does not inherit a deprecated model-catalog status; retain pure mode and deny-all permissions.
