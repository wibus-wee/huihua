# Huihua v0.4.8

This release makes the parser graph portable across platform seams and reads the fx v2 journal record types added in fx 0.0.17.

## Features

- Run the same parser graph on portable platform seams: byte access, path algebra, Buffer, home directory, environment lookup and SHA-256 are resolved per condition through `#fs #path #bytes #os #env #crypto` specifiers, so browser and Node entries share one parser implementation instead of a second copy.

## Fixes

- Read fx v2 `model_call`, `tool_running` and `runtime_context` records as system evidence instead of reporting them as unknown; `tool_running` remains a provisional duplicate of `tool_call` until the producer retires it.
- Refresh reviewed compatibility baselines for Claude Code, Codex, Copilot CLI, Droid, fx, Hermes, Kimi, OAR, OpenClaw and Qwen, including Codex 0.170.0 response metadata variants and Copilot CLI 1.0.114 content-block field movement.
- Keep the live producer harness working against `@botiverse/oar` 0.118.0 (new `piRuntime.session` export and `observe/index.js` entry) and Grok 1.0.77+ title-fallback versions.
