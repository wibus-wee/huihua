# Huihua v0.4.5

This release improves Copilot usage reporting and preserves additional OAR session activity.

## Improvements

- Read Copilot CLI per-call `session.usage_record` usage data while excluding cumulative checkpoint and shutdown metrics from response token totals.
- Preserve OAR `turn_active` events as system events with their original payload and attribution.
- Expand compatibility coverage for recent Claude Code and Codex formats.
